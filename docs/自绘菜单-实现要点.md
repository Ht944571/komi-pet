# 自绘右键菜单（MenuSession）实现要点与踩坑

> 由 `MEMORY.md` 迁出（2026-09-30）：这些要点**改菜单前必读**，但不必每次开工都读。
> 相关：`docs/工作交接-2026-09-28.md` §9/§11/§15、`docs/形态收敛-2026-09-28.md`。
> 代码位置：`app/wb_whale_win.py` 的模块级类 `MenuSession`（布局/命中/绘制/消息循环一体，
> `run(owner_hwnd, pt)` 模态返回选中 cmd / 0，对齐 `TrackPopupMenu(TPM_RETURNCMD)` 语义）。

## 为什么不用系统菜单 / owner-draw

Win11 系统菜单窗口的背景合成不可控（`MIM_BACKGROUND` 铺底不可靠）→ 未绘制区在 DWM 合成时
**透出下层**（视觉 = 文字与桌面内容「重叠」），hover 切换的擦除时机也管不到；在 `TrackPopupMenu`
黑盒里补背景/擦除是打地鼠。改成**与桌宠本体同款的自绘分层窗口**（`UpdateLayeredWindow`，
逐像素 alpha）后：背景天然不透明、每帧全量重绘（无残影）、真圆角 + 阴影。

## 🔴 硬规则（踩过的）

| 规则 | 后果 |
|---|---|
| `WS_EX_LAYERED = 0x80000` **必须带** | 漏了 `UpdateLayeredWindow` **静默失败、窗口全透明**（正是「字体重叠」现场）。别误用 `0x08000000`（那是 `WS_EX_NOACTIVATE`） |
| **扩展样式一律具名常量、绝不写字面量** | 把 `0x20` 当 TOPMOST 写进去 = **`WS_EX_TRANSPARENT`**（鼠标穿透 + 被每秒抢置顶的桌宠压住）；TOPMOST 是 `0x8` |
| 手抄 Win32 常量同属高危 | `MF_OWNERDRAW=0x100`、`WM_MEASUREITEM=0x002C`、`WM_DRAWITEM=0x002B`（`0x0211/0x021B` 是 `WM_ENTERMENULOOP/EXITMENULOOP`）。[G8] 断言对 SDK 真值锁死 |
| `WNDCLASSW.lpfnWndProc` 是 `c_void_p` | WINFUNCTYPE 需 `ctypes.cast(..., c_void_p)` + **模块级持有回调**防 GC |
| **建窗后 `_pin_top()`，且每次绘制后再钉一次** | 两侧都在 topmost 带 → **z 序 = 谁最后置顶**（不钉时实测 桌宠#1 / 菜单#14） |
| **菜单开着时 `_anim_tick` 照跑**（只闸 `tick` 的查库+气泡刷新） | 两个都闸 → 人物当着用户的面**冻住**。配套：`_move_window` 在 `_menu_open` 时带 `SWP_NOZORDER`；`_pet_mouse` 直接 return 0 |
| **子菜单必须画进子菜单自己的 surface** | `_render_sub` 曾写 `s = self.surf`（父菜单的）→ 子卡片下面那段只剩阴影灰块，且 `present` 按 bitmap 尺寸上屏 → 子菜单窗口被撑成**父菜单高度**（用户报障「设置面板设置时会有空出来」） |
| `_menu_wndproc` 不能所有消息 `return 0` | WM_CLOSE 被吞 = **幽灵菜单**（关不掉、`tick` 永远被闸）。现在 WM_CLOSE → `finish(0)`，其余走 `DefWindowProcW` |
| 子菜单 = 独立 `WBMenuClass` 窗口（`WS_EX_NOACTIVATE`） | 鼠标仍由**父窗口** `SetCapture` 裁决（单窗口集中制） |

## 卡顿三来源与修法（2026-09-29 实测）

1. **`_recreate_window` 会无条件重建帧缓存**（525 帧解码 + 重采样 ≈ 3.2s）→ 点「想法气泡」冻 3.2s。
   现在帧缓存只认**显示尺寸**（`_cache_sig()`）；真改尺寸走**后台建**
   （`_rebuild_cache_async` / `_wait_cache_new`，UI 18ms 返回），期间旧缓存**拉伸顶住**
   —— 那 16% 尺寸跳过规则要对 `_cache_building` 放行，否则缩放跳档她会**消失**。
2. **菜单项构建每次查库**（~10ms/次）→ `_stale_list_cached(20s)` TTL。
3. **子菜单一 hover 就展开**（12ms/次 + 看着闪）→ 停留 `SUB_OPEN_DELAY_S=0.14` 才开。

- `tools/_diag_menu_live.py` —— 对运行中桌宠的只读 E2E（PostMessage 弹真菜单 → z 序 / 命中 / capture / hover）。
