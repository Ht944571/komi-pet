# 路线 3 · 移植实施方案：鲸鱼气泡桌宠 × WorkBuddy 用量看板

> 目标：把 DeepSeek-Balance-Whale-Widget 的“桌宠 + 想法气泡”交互形态移植进本机
> WorkBuddy 用量看板，数据源替换为**本机 wb_api + workbuddy.db 活跃会话**（积分/Token/用时），
> 保留原有用量数据的获取、刷新与展示逻辑，仅换呈现载体与交互入口。
> 上游代码（MIT）已下载参考：`upstream/DeepSeek-Balance-Whale-Widget-main/`（v0.2.10）。

## 一、上游可借鉴清单（来自 lib/index.js 实测通读）

| 上游实现 | 借鉴方式 |
|---|---|
| 气泡 = 代码绘制 SVG（viewBox `0 0 1026 700`），白色圆角框 + 中央三行文字，非图像 | 原生端用 GDI+ 圆角矩形 + 白色填充 + 深色文本复刻“白色想法气泡”；避开复制其具体 SVG 源码，仅同构复刻 |
| 文字颜色 `#536ba9`（偏蓝紫）、气泡白色、整体圆润 Q 版 | 作为配色参考（气泡白 / 文字蓝紫 / 描边淡紫） |
| “已思考(用时 X秒)＞ 文案”的标题行 + 两行副内容的三行结构 | 映射为：标题（活跃状态/最近轮用时）+ 数值行（积分/Token）+ 提示行（最近活跃时间/项目） |
| 随机台词机制：点击气泡 → 加权随机台词段，5s 自动收起 | 移植文案库（卖萌/状态吐槽/穷光蛋风格），数据缺省时显示台词 |
| 60s 轮询 + 数字滚动动画 | 复用本 skill 已实现的 wb_hover_core 轮询（1s 活跃/60s 汇总），数字变化时做滚动或脉冲动画 |
| 拖拽 + 四边吸附 + 左吸附水平镜像 + 按压 Q 弹（`transform-origin:50% 100%` 底部锚定压扁） | 原生端：拖拽贴边吸附(±8px) + 靠左自动镜像 + 按压 scale(1.06,0.92) 底部锚定回弹 |
| 汉堡菜单：0.6–2.5× 缩放、音效开关、气泡开关、音量 | 原生端做右键菜单（打开看板/气泡开关/退出/缩放档位） |
| 立绘 = 独立 cut-out PNG（assets/DSniang1.png） | **版权独立判断点**：仓库 MIT 通常覆盖仓库内容，个人自用合规，但立绘为第三方美术风格；本方案默认自备素材 |

## 二、目标形态（Windows 原生，延续现有技术栈）

- **载体**：WS_EX_LAYERED 分层窗口，尺寸约 260×320，右下角常驻；**气泡在鲸鱼头顶偏右/居中弹出**，整体随气泡出现自动扩窗
- **鲸鱼**：位图（透明 PNG 或代码自绘矢量鲸鱼渲到 DIB）+ 屏幕内放置；气泡绘制在其上方
- **气泡内容（三行，对齐参考图）**
  - 行 1（粗，蓝紫）：`已运行 X 个会话` / `刚结束一轮(用时 …)` / `余额 …` 风格标题 —— 取自活跃会话状态
  - 行 2：`本轮 12.3 分 · 45.6K tok`
  - 行 3：`项目 · 最近活跃 2分钟前`
- **数据链路（零改动）**：`wb_hover_core.query_db / api_healthy / fmt_*` 已提供全部；看板 URL 双击进入
- **交互**：单击气泡=切台词/刷新；双击鲸鱼=开看板；右键=菜单；按住拖动=移动+贴边吸附记忆；外部点击=气泡收起
- **置顶/不抢焦点/点击透传**：沿用 b_hover_win 已验证的 TOPMOST、MA_NOACTIVATE、per-pixel alpha、WndProc 桩生命周期等全部经验

## 三、需要拍板的 3 点（确认后即开工）

1. **鲸鱼素材**：A) 我代码自绘“简约矢量鲸鱼”（圆润蓝白，随窗口缩放，最省事、无版权顾虑，推荐）；B) 你提供 PNG（透明 cut-out）；C) 直接复用上游 assets/DSniang1.png（个人自用 OK，商用请自行确认）
2. **与现有悬浮球关系**：A) 桌宠替换悬浮球（原 88px 圆球退役）；B) 并存（桌宠常驻主入口，圆球保留作极简状态点）
3. **气泡信息粒度**：A) 单句总结（对齐原版台词风格，最像参考图）；B) 三行详情（上文行1-3）；C) 可点开的大面板照旧（大面板仍由双击进入，气泡只放短信息）

## 四、实施阶段拆分

1. P0 桌宠壳：分层窗 + 透明 PNG/矢量鲸鱼渲染 + 气泡白框(圆角+小尾巴)绘制 + 置顶/不抢焦点
2. P0 交互：拖动贴边吸附/记忆、单击切台词、双击开看板、右键菜单、外部点击收起
3. P1 数据：接入 wb_hover_core 实时数据 → 三行气泡 + 状态台词（活跃/空闲/超支/离线）
4. P1 动效：气泡出现缩放、按压 Q 弹、数字滚动、靠左镜像
5. P2 收尾：开机自启选项、卸载说明、文档、与悬浮球/看板共存验证
