## 三、还有价值、别当废纸的三处

1. **`④` 里的量化约束**：66ms 帧、粒子上限 24、三态立绘（idle/happy/pout）——
   这些是设计决策，后来固化成了 `wb_motion.py` 的令牌。改动画前值得回看当时的取舍理由。
2. **`⑥` 揭示的问题**：`_eye_config.json` 原先是「肉眼估算 + 三张立绘共用一套坐标」
   导致 pout 眯眼 / happy 歪头全对不上。现在的逐立绘标定就是这么来的。
3. **`①` 的上游协议是 MIT** —— 这也是当初敢于移植的许可前提，记录在案。
