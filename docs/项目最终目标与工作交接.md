## 1. 这个项目最终要做什么（North Star）

> **做一个可跨平台安装、开箱即用的桌面宠物；它站在桌面上，替你盯着各个 AI agent 的用量。**

拆成四句可执行的目标：

| # | 目标 | 现在的状态 |
|---|---|---|
| **G1** | **它是一个桌面宠物**：立在桌面最上层、透明、不打扰任何其他窗口 | ✅ 2D / 3D 两种形态都做到 |
| **G2** | **它展示各 agent 的用量**（轮次 / 调用 / Token / 模型 / 项目 / 会话 / 趋势） | ✅ 数据层与看板已完成 |
| **G3** | **用户自主选择接入哪些 agent**（可开关、可看到能力） | ✅ 登记册 + 看板接入面板 |
| **G4** | **跨平台可直装**：Windows / macOS / Linux 各一个安装包，双击即用 | ⏸️ 方案已定，**实现未开始** |

**当前的产品重心**：从 2026-09-25 晚起，重心转向 **G1 的形态升级**——把 2D 立绘桌宠做成 **3D 立体摆件**（依据用户提供的参考视频）。G2 / G3 已可用，G4 是下一阶段。

## 3. 两条产品线的关系（**当前最重要的架构事实**）

现在项目里**同时存在两套桌宠**，由守望按设置切换：

```
                    ┌── 2D 桌宠   hover.py → wb_whale_win.py   （GDI+ 分层窗口，零第三方依赖）
pet_mode ───────────┤
                    └── 3D 桌宠   wb_pet3d.py + wb_tray.py     （GL → ULW 分层窗口，见下）
```

| | 2D | 3D |
|---|---|---|
| 渲染 | GDI+ 画立绘 | moderngl 渲染 50 万面 GLB |
| 依赖 | **零第三方**（纯标准库） | moderngl / glfw / trimesh / pygltflib / Pillow |
| 体积 | 立绘 24 张 | 模型 35.6 MB |
| 视角 | 固定 | **自由环绕** |
| 眨眼 | 程序化盖板 | morph target（眼睑盖板下滑） |

**为什么并存、不替换**：
1. 2D 是成熟的、零依赖的，**也是 3D 出问题时的退路**
2. 3D 引入第三方依赖，不是所有环境都装得上
3. 用户明确选过「2D 与 3D 共存可切」

**切换方式**：改 `app/.whale_settings.json` 的 `pet_mode`（`"2d"` / `"3d"`）→ 重启守望后生效。

## 4. 模块结构

```

├─ 3D 线（新）

│   └─ assets3d/pet_v2_rigged.glb
├─ 2D 线（原）
│   ├─ hover.py             入口（按平台分发）
│   ├─ wb_whale_win.py      Win32 桌宠主体（~3200 行）
│   ├─ wb_whale_watcher.py  守望：拉起 / 崩溃重启 / 自启注册 / 联动关闭（**已支持 pet_mode**）
│   ├─ wb_motion.py         动效令牌（时长/幅度/颜色的唯一出处）
│   ├─ wb_accessories.py    配件层（槽位 / 几何 / 动效）
│   ├─ wb_follow.py         跟随模式（WinEvent + 去抖）
│   └─ wb_hover_core.py     数据公共层（路径 / 取数 / 格式化 / 位置记忆）
├─ Agent 接入
│   ├─ wb_agent_registry.py 登记册读取层（唯一声明处，按 mtime 缓存）
│   └─ wb_agent_presence.py 活跃探测（L1 hook / L2 日志 / L3 进程端口）
└─ wb_usage/                数据层 + 8801 接口 + 看板前端（跨平台，纯标准库）
```

**最该先读的三个文件**：`wb_pet3d.py`（现状主体）→ `wb_whale_watcher.py`（生命周期）→ `wb_agent_registry.py`（接入扩展点）。

## 5. 关键决策与理由（别推翻它们，除非有更好的）

| 决策 | 理由 |
|---|---|
| **透明窗口用 `UpdateLayeredWindow(ULW_ALPHA)`** | **逐像素命中测试是系统白送的** → "3D 旋转时剪影每帧在变"这个在别的方案里最难的问题，在这里**根本不存在**（不需要凸包近似、不需要轮询光标） |
| **不走 Godot / Tauri 做 3D 表现层** | 它们的穿透要靠凸包近似或轮询；而现有窗口壳已验证且 100% 可复用 |
| **动画用「程序化变换 + morph target」，不用骨骼 / 关键帧** | 自由视角旋转下，**预渲染帧只能覆盖固定角度**；程序化变换天然与视角无关 |
| **眨眼用"肤色盖板下滑"而不是真眼睑** | AI 模型**没有眼睑几何**；平涂 NPR 下视觉等价，只需 2 个 morph target |
| **底模重做（多视图 + 50 万面）优于后处理修补** | 实测：换底模带来的提升**远大于**任何贴片/平滑处理 |
| **Agent 接入用声明式登记册** | 新增 agent **只改 JSON 不改代码** |
| **不碰 agent 自己的配置文件** | Clawd 那种"往 20 种格式写 hooks"要 100 文件 / 3.7MB，我们不复制那个代价 |

## 6. 日常操作手册

### 跑起来

```bash
# 3D（当前默认）
cd /d D:\workbuddy\古见同学桌宠\app
C:\Users\htft2\.workbuddy\binaries\python\versions\3.13.12\python.exe wb_pet3d.py

# 2D
... python.exe hover.py
# 跑 20 秒自动退出（验证用）
... python.exe wb_pet3d.py --seconds 20
# 出一张"自画像" PNG（不依赖 Z 序，验证渲染内容用）
... python.exe wb_pet3d.py --shot out.png
```

### 交互

左键拖=移动 · 右键拖=环绕视角 · 滚轮=缩放 · 单击=戳（惊讶）· 双击=摸头（开心）
**退出：右键托盘图标 → 退出古见同学**（窗口本身没有关闭按钮，也不接受键盘）

### 改配置

| 文件 | 管什么 |
|---|---|
| `app/.whale_settings.json` | `pet_mode`(2d/3d) · 2D 的配件/气泡/联动关闭 |
| `app/.pet3d_settings.json` | 3D 的视角(yaw/pitch/dist) · 位置 · `wander` / `follow` / `bubble` 开关 |
| `app/assets/_agents.json` | **Agent 登记册**（新增/启停 agent 只改这里） |

### ⚠️ 沙箱环境限制（会反复遇到）

**每个工具调用结束会回收后台进程**——`DETACHED_PROCESS` / `CREATE_NEW_PROCESS_GROUP` / `cmd start` 三种都试过，全活不下来。
→ 想长期运行，只能靠**已有的自启机制**（守望已在 HKCU Run 里），或在用户自己的终端跑。
