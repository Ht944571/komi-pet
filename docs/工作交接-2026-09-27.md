## 1. 自更新（G4 的分发闭环）

**发版三步**（`app/wb_version.py` 的 `VERSION` 是版本号的唯一出处）：

```bash
# 1) 改 app/wb_version.py 的 VERSION
<venv>/python.exe packaging/build_win.py
<venv>/python.exe packaging/publish_win.py --notes "改了啥"      # 出 update.json（含 sha256）
```

把 `zip + update.json` 传到同一位置 → 客户端 `--set-update-source <地址>` 指一次。
**默认零联网**（没配源一个请求都不发）；更新是用户点右键才下载替换，不是静默升级。

替换流程的关键：**由"新版本的 exe"执行**（正在跑的 exe 与 `_internal/*.dll` 被锁着，
当前进程改不了自己）→ 解压到 `staged/` → 用 staged 里的新 exe 起 `--apply-update` → 老进程退出。

## 3. 形态尺寸归一（`ac7dce7`）

**根因**（实测，不是感觉）：v3 八态共用画布，构建期只归一到「脸宽一致」，
**姿势高低没管过** → 屏幕内容高 139~258px（**1.86×**）。更关键：`_draw_state_fade`
有溶解闸门（八态局部差异 78~218 > 阈值 60）→ **硬切** → 尺寸突跳。

**改法**：`_state_size()` 按视觉大小 √(w·h) 归一 + `_size_factor()` 缓入（0.20s）；
`_build_sprite_cache` 按每态系数预缩放；缓存命中容差 ±2px → `max(2px, 16%)`（顺带修掉
"悬停时一直命中不了缓存、每帧重采样"的隐性开销）。

| | 改造前 | 改造后 |
|---|---|---|
| 姿势高度极差 | 1.86× | **1.55×** |
| 脸部尺寸变化 | 1.00× | **1.20×** |

⚠️ **α 默认 0.5 而不是 1**：α=1 能把高度差压到 1.30×，但**脸会变 1.45×** ——
chibi 角色"头的大小"比"整体高度"更影响观感，宁可保留高度差也不动脸。旋钮：`MOTION.SIZE_NORM_ALPHA`。

## 5. 写字本子（`c17e6fe`）

参考视频 `Q版古见同学写字.mp4` 拆三段：写字(0~3.3s) → 翻页(3.4~3.7s) → 展示(3.7~4.0s)。

### 触发条件：与气泡 OK 态**共用同一个判据**（最重要的一条）
气泡完成态一直靠 `_sync_bubble_mode()` 里 `prev_active_n > 0 → 0`。本子若另算一套，
迟早出现"气泡说完成了、本子还在写" —— **比不做还糟**。所以驱动就写在**同一函数的同一处**。

| 事件 | 判据 | 动作 | 时长 |
|---|---|---|---|
| 任务开始 | `len(active)>0`，此前 hidden | `appear` 拿出本子翻开 | 0.32s |
| 进行中 | `len(active)>0` 持续 | `writing` 逐行落墨，满 9 行翻页 | 每行 ~0.62s |
| 任务完成 | `prev>0 且 len(active)==0` | `present` 翻页+举起展示 | 0.42s，保持 6s |
| 新一轮 | 展示中 `len(active)>0` | 收旧页 → 直接接着写（换新页） | — |

两个细节：**首次取样只建基线**（否则启动瞬间把已在跑的任务误判成"刚开始"）；
**完成后的统计要留住**（`active` 一空数据就没了 → writing 期间每 tick 刷最新值）。

### 几何两条硬约束
1. **不遮眼睛**：上沿 ≥ 该态**眼位**+1.5%。八态眼位差很大（idle 0.468 / stone 0.510 /
   pout 0.533 / blush 0.577），**写死一个比例必遮某些态的脸**。眼位取自 `_eye_config.json`。
2. **不出窗口**：宽 ≤ 内容宽 62%(展示)/46%(写字)；底不越脚下（跨页素材是横版 1.36，
   只按高度放大会宽过肩膀）。

展示页：整页手写墨迹 + 页脚**可读的真实数据**（用时/tokens/积分）+ 小爱心；
**点本子 → 打开看板**；写字态不抢点击。

## 8. 今天踩的坑（都写进代码注释了）

### 颜色（项目级规矩）
`Surface.ellipse/poly/ctext` 收的是 **ARGB**。`INK = 0x746556` 只有 6 位 → **alpha=0 →
墨迹全透明且不报错**。表现是"页面上只有爱心看得见"（爱心恰好写了 `0xFFE58AA0`）。
**新加任何颜色都要补 `0xFF`。**

### 动画状态机
推进循环的判据必须用**单调递增的累计量**（`total_lines`），不能用"每页归零"的 `lines` ——
后者会让 `while want > lines` **永远追不上 → 死循环 → 卡死消息循环**。桌宠挂起/睡眠后
`now` 会跳很远，实测挂起 60s → 补成 97 行 / 第 11 页。

### 批量插代码（同一天踩了三次）
1. **锚点作用域**：`state = "happy" if ...` 在 `else:` 分支里 → 插进去的代码受分支管
   （`UnboundLocalError`，且**语法合法**）。
2. **锚点在方法体内** → 整段缩进多一层变成**嵌套函数**（语法通过、运行才炸）。
3. **锚点撞车**：`ph = lay["pet_h"] - 8*sc` 在多个方法都有 → 命中**第一个**，
   分支插进了自己刚写的另一个方法（静默失效 + 潜在递归）。
   → **找锚点必须限定范围**（从目标方法的 `def` 行之后找）；修复用**确定性重建**
   （删光现存块、插入写死缩进的一份），别在原块上叠加。
4. 另：判断"文件里有没有这段"别用 `'xxx' in 全文`（注释提到就误判），要正则匹配**真语句**。

### 素材 / 打包
- 帧素材**别按 1167×1570 存**：49 帧那样 49MB；存成显示尺寸（420 宽）后 **6.3MB**。
- 内容框必须取**实际非透明像素**的紧框，不能用"摆放矩形"（含透明留白 → 内容框变整张
  画布 → 气泡/命中区/本子全顶歪）。
- 字段初始化顺序：`_anim_image` 在 `_build_sprite_cache`（早于字段赋值）里被调 →
  `AttributeError` → 改用 `getattr` **惰性初始化**（项目旧例 `_acc_image`）。

### 测试基线（判据共用的正常副作用）
本机**真的有会话在跑** → 桌宠进任务态 → 两个要验"v3 立绘路径"的测试被干扰。
→ `test_hit_regions` / `test_scale_switch` 加守卫：`app._anim_clip = None;
app._nb.phase = "hidden"`；`test_hit_regions` 的 G0 改为"八个 v3 态齐全"
（`__anim__` 是合法新增伪态）。
