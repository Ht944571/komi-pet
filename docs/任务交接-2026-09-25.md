## 3. 本会话踩坑实录（后续开发必读）

| # | 坑 | 解法 |
|---|---|---|
| 1 | **进程内二次 GdiplusStartup** → `Surface` 类级字体缓存句柄失效，下一个实例首帧 `MeasureString` 访问冲突 | 测试多实例必须**复用同一 WhalePet**（一个测试文件只创建一次，最后统一 close） |
| 2 | bash 双引号里的**反引号被命令替换吞掉**，文档长段落写入后缺片段 | 改文档长段落用 **Edit 工具**，别用 `py -c` 内嵌反引号文本 |
| 3 | **.gitignore 不支持行内注释**：`app/wb_usage/data/  # 注释` 整串成无效规则，989MB 差点入库 | 注释独立成行；`git ls-files` 提交前必查 |
| 4 | `wb_whale_win` 主文件**无模块级 sqlite3**，新加 DB 方法要局部 `import sqlite3`（NameError 被吞成静默失败） | 新方法跑通前先造最小复现 |
| 5 | **WAL 库 VACUUM 产出先进 WAL**，主文件要 `wal_checkpoint(TRUNCATE)` 才立即缩 | `vacuum_db()` 已内置 |
| 6 | **PAT 缺 `workflow` scope** 推不动 workflow 文件——网页勾选或网页上传二选一 | 见 §2① |
| 7 | 目视标定网格必须**每 0.05 一条线且每条带标注**——无标注粗网格读错行距，整批偏 0.1 | `calib_face.py --grid` |
