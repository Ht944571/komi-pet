## 0. 一句话结论

新素材与现有 Q 版**本来就是同一条血脉**（淡紫高光带、半阖暗瞳、腮红、领结、藏青制服）。
所以本方案**不是重做，而是「Q 版精修升级」**：把新参考作为 **Q 版 v2** 的设计规范，
**升级现有 6 个静态态**、**新增 2 个反应态**（惊讶 / 开心眨眼）、并**补齐待机与过渡动效**。
**高冷版保持不动**（它是另一条审美线：大眼虹膜、长身形）。

## 1. 设计原则（与现状的关系）

| 原则 | 内容 |
|---|---|
| **升级，不是替换** | 新参考 = 现有 Q 版的精修版。血缘一致（高光带、暗瞳、腮红、领结、制服），不做推翻式重设计 |
| **两条审美线并存** | Q 版（萌系 chibi，本方案升级它）∥ 高冷版（标准少女比例，不动） |
| **风格统一** | 全项目沿用同一渲染语言：粗细分明的曲线描边 + 3 层硬边 cel + 沿轮廓亮边 + 低饱和配色（见《配件美术规范》） |
| **一切数字成令牌** | 尺寸、比例、色值、时长全部进 `wb_motion.py` 风格的令牌表（§6），不写死在立绘或代码里 |
| **静态成规范，动效可验证** | 每个态给：占比、色值、关键线位；每个动效给：时长、缓动、帧数、验收方式 |
| **原创重绘，不写官方素材** | 古见同学是版权角色。沿用项目既有做法——**生成/绘制原创同人风格图**，不复制官方立绘；README「素材与角色说明」需覆盖这一点（项目已上 GitHub，合规不能缺） |

## 2. 外形设计

### 2.1 造型比例（Q 版 v2）

以三视图（前 / 侧 / 背）实测为准。单位：以**头高 = 1**。

| 部位 | 比例 | 说明 |
|---|---|---|
| 头高 : 全身高 | **1 : 1.6** | **2026-09-25 与 3D 摆件统一**。当前 Q 版约 1:2.3 → 新版头**大幅放大**，是盲盒/扭蛋比例 |
| 头宽 : 头高 | **0.86 ~ 0.92** | 头帘呈「圆弧壳」罩住上半脸 |

| 后发长 : 身高 | **0.55 ~ 0.62** | 整片**发帘**垂至腰下（背面是整幅「发幔」）|
| **发幔底端** | **与脚齐平** | **2026-09-25 由 3D 参考补入**：发幔两侧垂下、底端与脚同高，把身体框在中间 |
| 身体 : 全身 | **1 : 2.6 ~ 2.8 的下半 1/2** | 短腿 chibi |

| 裙 : 身体高 | **0.28** | 百褶短裙 |

## 3. 静态状态表现（8 态）

现有 6 态**升级为新造型**，视频提取 2 个**新增反应态**。每个态给**交互映射**。

| 态 | 表现（基于新造型） | 触发（交互映射） | 立绘状态 |
|---|---|---|---|
| `idle` 待机 | 前视站姿，半阖暗瞳，小腮红，手垂身侧（= 三视图前视图） | 默认 | 升级 |
| `happy` 开心 | 嘴角微上扬、眼微弯、腮红稍重 | 任务完成 / OK 态 | 升级 |
| `pout` 闹别扭 | 眉微下压、嘴角撇、头微侧 | 报错 / 失败 | 升级 |
| `shy` 害羞 | 头微低、腮红大面积加重、眼神微飘 | 被打趣 / 长时间注视 | 升级 |
| `stone` 石化 | 面无表情、眼神呆滞（留白） | 卡住 / 无语 | 升级 |
| `blush` 害羞红晕 | 满脸红、眼神躲闪、嘴微张 | 强烈害羞 | 升级 |
| **`surprise` 惊讶** 🆕 | **睁大眼 + 张嘴"o" + 腮红加重**（视频 t≈8.6） | **单击 / 戳一下**（对应现有"被戳一下愣两秒"） | **新增** |
| **`joy` 开心眨眼** 🆕 | **单眼 wink + 食指抵脸颊 + 大笑腮红**（视频 t≈9.7） | **双击 / 摸头**（对应现有"摸头→爱心"） | **新增** |

**交付物**：8 态 × 2 朝向 = **16 张立绘**（Q 版 v2）。
（沿用现有 `pet_<state>.png` / `pet_<state>_f.png` 命名与 `_eye_config.json` 锚点体系，兼容现有代码）

> **约定**：`surprise` / `joy` 只做**短时反应**（≤1.2s），结束后**回到 idle**，
> 不改变当前「今日量/数据」显示。它们是**动效层的瞬态**，不是数据层的态。

## 4. 动效设计（视频提取 + 现状对齐）

### 4.1 待机动画

| 元素 | 规格 | 对齐现状 |
|---|---|---|
| 呼吸 | 上下浮 **2px**，周期 ≈ 2.2s，缓入缓出 | 现有 `BREATH_AMP_PX = 2.0` 保留 |
| 轻摆 | 身体**水平微摆 ±1.5px**（视频里远距离站姿的轻微晃动），周期 ≈ 4s，**相位与呼吸错开 90°** | 新增（视频依据） |
| 眨眼 | 沿用现有**眨眼标准 ④⑤**（状态调制 + 部分眨眼 65% + 慢眨），不动 | 已实现 |
| 发梢 | 发幔末端随呼吸 **±1px** 轻微起伏 | 新增（发幔是新版主角） |

### 4.2 交互反馈动作

| 交互 | 状态序列 | 时长 | 粒子 |
|---|---|---|---|
| **单击 / 戳** | idle → `surprise`（2 帧渐入）→ 停留 ≈1.0s → 回 idle | ≈1.2s | 无 |
| **双击 / 摸头** | idle → `joy`（2 帧渐入）→ 停留 ≈1.4s（期间眨眼 1 次）→ 回 idle | ≈1.6s | 爱心 3–4 颗（现有） |
| **长按 / 拖拽** | 现有拖拽 + 吸附逻辑不变 | — | 无 |

**关键**：`surprise` 与 `joy` 是**同一交互轴的两端**（轻戳→愣住 / 深摸→开心），
**不要都用 `happy`** —— 那是旧版的粗糙处（一次点击和一次深摸区分不开）。

### 4.3 状态切换过渡

视频里反应**不是瞬切**，而是有 **2–3 帧渐进**（抬手 → 微张嘴 → 全惊讶）。沿用这个原则：

| 切换 | 过渡 | 帧数 @66ms |
|---|---|---|
| idle ↔ 任何反应态 | **2 帧渐入 / 2 帧渐出**（scale 96%→100% + alpha 0→1），不做硬切 | 各 2 帧 |
| 反应态 → idle | 先**快速眨眼 1 次**再回 idle（显得"回神"） | +1 帧 |
| 表情 A → 表情 B | **禁止 A 直接换 B**：必须经 idle 回一站，或走 reaction overlay | — |

**实现约定**：过渡用**位移 + 缩放**（drop/hug 曲线，配件层已有），**不做 alpha 淡入淡出**
—— GDI 的 AlphaBlend 没有全局 alpha（踩过的坑），alpha 只靠**缩放 + 位移**表达"出现/消失"。

## 5. 与原有设计的调整点（diff）

### 5.1 外形

| # | 项 | 原设计 | **调整点（新版）** | 理由 |
|---|---|---|---|---|
| 1 | 头身比 | 约 1 : 2.3 | **1 : 1.6（头大幅放大，1.5 头身）** | **与 3D 摆件统一**（2026-09-25 决策）；盲盒/扭蛋比例 |
| 2 | 头帘 | 有弧度但偏碎发 | **整片圆弧壳，发帘下沿齐颧骨** | 新参考的标准化头帘，剪影更干净 |
| 3 | 高光带 | 有但位置/宽度不统一 | **统一为一道水平带 `#7D6B87`，三朝向同位** | 它是视觉签名，必须成令牌 |
| 4 | 后发 | 散碎垂发 | **整幅发幔垂至腰下，背面整幅覆盖** | 背面不再靠脑补 |
| 5 | 瞳 | 半阖暗瞳（一致） | 保持一致，**更干净**（单高光、无多余反光点） | 精修，不变性 |
| 6 | 制服 | 单排模糊扣 | **双排明扣 + 白翻领 + 口袋线** | 新参考的细节升级 |
| 7 | 裙 | 简单轮廓 | **百褶（暗褶线 + 短褶 + 勾边）** | 新参考的细节升级 |
| 8 | 头顶 | 无 | **一处小翘发** | 识别点 |

### 5.2 状态

| # | 态 | 原设计 | **调整点** |
|---|---|---|---|
| 1 | 现有 6 态 | 旧造型 | **全部重绘为新 Q 版 v2 造型**（比例/高光带/发幔/制服裙细节） |
| 2 | 交互反应 | 只有 `happy`（单击双击不分） | **拆成 `surprise`（单击）+ `joy`（双击）** —— 区分轻戳与深摸 |
| 3 | 生气 / 报错 | `pout` 直接瞬切 | **走 2 帧渐入 + 回 idle 前先眨 1 次**（渐进过渡） |

### 5.3 动效

| # | 元素 | 原设计 | **调整点** |
|---|---|---|---|
| 1 | 待机 | 仅呼吸 2px | **+ 水平轻摆 ±1.5px（相位错开 90°）**（视频依据） |
| 2 | 发梢 | 无 | **发幔末端 ±1px 随呼吸起伏**（发幔是新版主角） |
| 3 | 过渡 | 硬切 | **渐进 2 帧（位移+缩放）**，回 idle 前先眨 1 次 |
| 4 | 眨眼 | 标准 ④⑤（已实现） | **不动** |

### 5.4 配色（改动最小的一栏）

| # | 项 | 调整点 |
|---|---|---|
| 1 | 线色 / 领结红 / 腮红 | **不变**（与现有令牌一致） |
| 2 | **发·高光带 `#7D6B87`** | **新增为令牌**（视觉签名，统一三朝向） |
| 3 | 外套 | 主体由 `#4E5684` 微降到 **`#3D3756`**（更深一档，衬出白翻领与明扣） |

## 6. 设计令牌（应进 `wb_motion.py` / 素材规范）

```python
# ---- Q 版 v2 造型 ----
QV2_HEAD_TO_BODY = 1.6          # 头高 : 全身高（与 3D 摆件统一，2026-09-25）
QV2_HEAD_W_H = 0.89             # 头宽 : 头高
QV2_HAIR_CURTAIN_EDGE = 0.58    # 发帘下沿 = 脸高 × 此值（齐颧骨）
QV2_HAIR_MANTLE_LEN = 0.60      # 发幔长 = 身高 × 此值

# ---- 高光带（视觉签名，三朝向同位）----
QV2_BAND_COLOR = "#7D6B87"
QV2_BAND_Y = 0.33               # 位于头高的 1/3
QV2_BAND_THICK = 0.045          # 带宽 = 头高 × 此值

# ---- 新增反应态 ----
STATE_SURPRISE = "surprise"     # 单击 / 戳 → 愣住（睁大眼+张嘴o）
STATE_JOY = "joy"               # 双击 / 摸头 → 开心（wink+指抵脸颊）
REACT_ENTER_FRAMES = 2
REACT_HOLD_S_SURPRISE = 1.0
REACT_HOLD_S_JOY = 1.4

# ---- 待机 ----
IDLE_SWAY_X_PX = 1.5            # 水平轻摆（呼吸相位 +90°）
HAIR_TIP_BOB_PX = 1.0           # 发幔末端起伏
```

## 7. 实现路径（可执行，复用现有管线）

1. **出图（生成式）**：以两张三视图作为**风格锚点**，用 ImageGen（image-to-image，
   `input_fidelity` 调高）**逐态生成** 8 态 × 2 朝向。提示词里**写死令牌色值**
   （尤其高光带 `#7D6B87`、藏青 `#3D3756`、领结红 `#B4364F`），防止各态漂移。
2. **抠图**：`tools/gen_to_asset.py`（已有，能抠棋盘格背景）。
3. **归一化**：裁到内容 bbox、统一到现有 Q 版画布尺寸（idle 823×981 基准）。
4. **锚点**：沿用 `_eye_config.json` v4 体系，`surprise` / `joy` 补两条锚点记录。
5. **接入**：沿用 `wb_accessories` 的槽位/几何/入退场（drop/hug）。
6. **验收**：三层校验（孤立图 → 语境图合成到立绘 → 真机 GDI 出图）；
   新增 **观感回归清单**：高光带位置三朝向一致、暗瞳无虹膜、过渡无硬切。

> ⚠️ 许可红线：出的是**原创同人风格重绘**，**不复制官方立绘**；
> README「素材与角色说明」需同步一句。生成素材文件里**不要带「AI 生成」水印**。
