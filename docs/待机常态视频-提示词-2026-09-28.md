# 视频提示词 · 待机 + 过渡 + 写字（2026-09-28）

## 成品长这样

```
坐着(循环) → 变困 → 困了(循环) → 醒来 → 坐着(循环) → 拿本子 → 写字 → 翻页 → 举本子展示
└────────────────── 要生成的 4 段 ──────────────────┘ └─── 已有参考视频 ───┘
```

| 段 | 来源 | 首帧 | 尾帧 | 时长 |
|---|---|---|---|---|
| **A 坐着** | 要生成 | `首帧_常态.jpeg` | **与首帧同一张**（可循环） | 4~5s |
| **B1 变困** | 要生成 | `首帧_常态.jpeg` | `首帧_困了.jpeg` | 4~5s |
| **B2 困了** | 要生成 | `首帧_困了.jpeg` | **与首帧同一张**（可循环） | 4~5s |
| **B3 醒来** | **不用生成** | — | — | **把 B1 倒放**即可 |
| **C 拿本子** | 要生成 | `首帧_常态.jpeg` | `尾帧_接写字首帧.png` | 3~4s |
| **D 写字** | 已有 | — | — | `Q版古见同学写字.mp4` |

**拼接方式（整条都是无缝的，没有硬切）**

| 接缝 | 怎么接 |
|---|---|
| A → B1 | 无缝：B1 的首帧 = A 的画面（坐着） |
| B1 → B2 | 无缝：B1 的末帧 = B2 的首帧（单手托腮） |
| B2 → B3 | 无缝：**B3 就是 B1 倒放** |
| B3 → A | 无缝：B1 倒放之后，末帧正好回到「坐着」 |
| A → C | 无缝：C 的首帧 = A 的画面 |
| C → D | 无缝：C 的末帧 = 写字视频的首帧 |

想让「坐着」持续更久，就**循环播放 A 若干轮**再往下接。
三张图都是 1024×1024，尺寸已对齐。

```
Q版古见同学（约2.5头身），紫黑色长直发，厚重齐刘海、头顶一条浅紫高光带、右侧长发垂至腰际；米白色脸蛋，大眼睛，脸颊有淡粉色圆形腮红；蓝灰色西装校服外套配白色衬衫、红黑斜条纹蝴蝶结、红黑条纹百褶裙、黑色过膝袜、棕色圆头皮鞋；日系赛璐璐平涂画风，粗黑描边，硬边双色阴影；纯白背景，没有任何背景元素；固定机位，不推拉、不摇移、不旋转、不缩放，全身入画、人物居中，机位与画幅和参考视频一致。

起初她安静地坐在地上，双手交叠放在身前膝上，眼睛半睁、神情平静；随后她的眼皮越来越沉，眨眼的间隔越来越长，脑袋开始一点一点向下沉；头沉到最低时轻轻一顿、像是猛地清醒了一下，但困意随即又涌上来；最后她抬起一只手托住下巴，另一只手搭在膝上，定格在单手托腮、眼睛几乎闭上的困倦姿态。动作舒缓连贯，约4秒完成，全程不要出现明显的大幅动作或夸张的哈欠。

首帧必须与「坐着」待机段的画面完全一致：双手交叠放在身前、眼睛半睁。
末帧必须与困了参考图完全一致：单手托着下巴、眼睛几乎闭上、另一只手搭在膝上。

全程镜头完全固定，画面除她以外全是纯白，无转场、无跳帧、无闪烁，人物的五官、发型、服装、比例保持稳定不变形。
```

> **B3（醒来）不用单独生成** —— 把 B1 **倒放**就是把「托腮」变回「坐着」，
> 观感正好是「她醒过来了、把手放回身前」，而且首尾帧天然对齐。

## 提示词 C · 拿本子（过渡段：坐着 → 准备写字）

```
Q版古见同学（约2.5头身），紫黑色长直发，厚重齐刘海、头顶一条浅紫高光带、右侧长发垂至腰际；米白色脸蛋，大眼睛，脸颊有淡粉色圆形腮红；蓝灰色西装校服外套配白色衬衫、红黑斜条纹蝴蝶结、红黑条纹百褶裙、黑色过膝袜、棕色圆头皮鞋；日系赛璐璐平涂画风，粗黑描边，硬边双色阴影；纯白背景，没有任何背景元素；固定机位，不推拉、不摇移、不旋转、不缩放，全身入画、人物居中，机位与画幅和参考视频一致。

起初她安静地坐在地上，双手交叠放在身前膝上，身前空无一物；随后她的右手向身后探去，从背后取出一本合起的本子和一支笔，收回身前；接着双手把本子摊开、放到膝上，右手握住笔，摆出准备写字的姿势；最后抬起眼睛看向正前方。整套动作分步清晰、舒缓连贯，约3~4秒完成，不能出现本子凭空出现或者突然跳到手里的情况。

首帧必须与「坐着」待机段的画面完全一致：双手交叠放在身前、眼睛半睁、身前没有本子和笔。
末帧必须与尾帧参考图完全一致：双手抱着摊开的本子、手握着笔、坐在那里看向正前方；机位、构图、光照、画幅与人物姿态完全对齐，以便无缝接上后面的写字视频。

全程镜头完全固定，画面除她以外全是纯白，无转场、无跳帧、无闪烁，人物的五官、发型、服装、比例保持稳定不变形。
```

## 负面提示词（各段共用）

```
水印，文字，字幕，logo，编号，边框；多手，多指，手指粘连，四肢变形，身体穿模；五官漂移，眼睛大小跳变，发型改变，服装改变，颜色跳变；镜头移动，推拉，摇移，旋转，缩放，转场，淡入淡出，闪白；背景元素，地面纹理，多余阴影；写实风格，3D渲染，厚涂，水彩，线条抖动，画面闪烁，跳帧，重影。
```

- **A、B1、B2**：都是空手的，可以额外加「本子，笔，书本，道具」。
- **C**：**不能加**那句，它必须有本子和笔。
