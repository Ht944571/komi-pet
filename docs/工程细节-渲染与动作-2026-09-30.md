## 1. 七段动作状态机（`wb_anim.PetPhase`）

流程：`idle`(循环) --空闲 180s--> `doze` --> `sleepy`(循环)；来任务 → `wake`(复用 doze 倒放)
→ `pickup` → `write`(循环) → 任务完成 `present`(复用 write 后段) → `idle`。

| 动作 | 素材 | 播法 | 触发 |
|---|---|---|---|
| `idle` / `sleepy` | `anim/<名>/` 107 帧 | 循环 | 常态 / 变困播完 |
| `doze` / `pickup` | 同上 107 帧 | 一次性 | 空闲超 180s / 坐着(醒来)来任务 |
| `write` | `anim/write/` **84 帧**（2026-09-30 换新素材） | 循环（**首轮播 0..83，之后只循环 33..83**） | 任务进行中 |
| `wake` | **复用** `doze` 倒放 | 一次性 | 睡着时来任务 |
| `present` | `anim/present/` 23 帧（**有自己的素材就用**，没有才回退 write 后段） | 一次性 | 任务完成 |

关键常量：`CLIP_OF={wake:doze, present:write}`；`FALLBACK_DUR={doze/wake/pickup:4.5, present:6.4}`；
`SPLIT_RATIO=0.816`；`HEAD_SCALE` 逐动作（**待机的头要放大 1.27**）。

素材 meta 可带两个键：
- **`loop_start`** —— 写字段的前摇长度（首轮从 0 播到 `count-1`，之后只循环 `loop_start..count-1`）；
- **`split`** —— present 段起点（有独立 present 素材时写 `0`）。
换写字段素材时这两个键要按实测边界重设。⚠️ `ANIM_MS` **必须与素材帧率同**，换素材后必查。

## 2. 动画节奏：41ms/帧（≈24.4fps）

2026-09-30 实测：`SetTimer(41)` 会被系统定时器粒度（15.6ms）拉到 **46.8ms**（21.5fps），
且本机 `timeBeginPeriod(1)` **无效**。现在走**高精度可等待定时器**
（`_make_hires_timer` + `CREATE_WAITABLE_TIMER_HIGH_RESOLUTION`）+ 后台线程投递 `WM_APP_ANIM`
（`_start_anim_clock`，**只投递消息、带合并语义**）；拿不到就退回 `SetTimer`，
时钟停摆由 `tick()` 的看门狗（>2s 无 tick）兜底。
⚠️ `_arm_timers` 接管时**不许**再挂 `ID_TIMER_ANIM`（双重投递 = 真跳帧）。

**循环动作固定步进**（每 tick 恰好 +1 帧，循环区间 = `AnimClip.loop_range(act)`），**不按墙钟取帧** ——
`time.time()` 只有 15.6ms 粒度 + `int(dt*fps)` 采样 → 会时而跳 2 帧时而停 1 帧（"一顿一顿"的根因）；
**一次性动作**（pickup/doze/wake/present）必须按墙钟走，否则赶不到末帧。

## 3. 帧几何、气泡、拖动范围

- 帧画布 **420×565**（源 1167×1570，bottom_aligned），**上方大量透明留白**。
- `_anim_content_top(lay) = _spr_rect.y + cbox[1] * _spr_rect.h`；**各动作 `cbox[1]` 不同**
  （write 0.3575 / pickup 0.4991 / sleepy 0.4938 / doze 0.5097 / idle 0.5257）→ 气泡锚点**必须动态取**。
- `_draw_bubble` 比 `_draw_pet` **先跑** → 读的是**上一帧**矩形（1 帧 41ms，无感）。
- 气泡位置 = `_bubble_box()`：`y = 帧内容顶 - BUBBLE_CHAIN_PX - 气泡高`（上沿钳 2px）；
  **唯一调参旋钮 = `BUBBLE_CHAIN_PX`（默认 40）**。改它**必须同步**：`_in_bubble()` 命中、
  `ok_spec(..., bub_y=)`（OK 态同源，否则切换会跳）、OK 粒子起点、测试基线。
- 文案：空态 = `("", "双击打开看板查看今日用量", "")`；row2 仅 `credit>0` 显示「本轮 X 积分 · tok · 用时」，
  否则「本轮 X tok · 用时」；渲染前**过滤空行并垂直聚拢**；`credit>0` 时 row2 染
  `C_TXT_PINK`（`0xFFE89AAE`，看板 `--sakura`）。
- 🔴 **气泡第三行已整体下线**（09-29 用户要求「任何时候都不要出现」）：`_bubble_lines` 直接
  `return row1, row2, ""`，说话态第三行也置空 → **气泡永远 ≤2 行**。时间线数据仍在右键「今日时间线」子菜单。
- 🔴 **拖动/贴边/启动摆放的上界 = 可见内容顶，不是窗口上沿**（09-29 用户报障「向上移动只能达到这里」）：
  窗口上沿之上还有一大段透明留白（气泡区 162*sc + 帧内上方透明边）。三处**同源**走 `_drag_bounds(lay)`
  = `min_y = 工作区上沿 - _dead_top + 4`；`_snap` 必须复用它（各写一份 → 吸附能推出范围 → 重启被拽回）。
  `_dead_top`：气泡开着 = 气泡上沿；关气泡 = 人物头顶（取不到上一帧矩形时走 `_static_content_top`，
  与 `_draw_anim_frame` 同源，保证贴顶的保存位置重启后原样恢复）。**想让头顶真贴屏 → 右键关「想法气泡」。**
  实测（用户设置 scale=1.0、工作区 2560×1368）：死空间 117px，上界从 `y=4` 放到 `y=-113`；
  关气泡后 `y=-281`（人物顶贴屏幕上边）。
  ⚠️ 外部进程量窗口尺寸前要先 DPI 感知，否则拿到虚拟化坐标（×2/3）。

## 4. 视线判定

鼠标落在 **443×465** 内才朝向鼠标（`wb_motion.GAZE_RECT_W/H`，**固定屏幕像素、刻意不乘 `scale`**）；
几何在 `wb_whale_win._gaze_box_center()` + `_cursor_in_gaze_box()`。

## 5. 采素材 / 转帧

```bash
cd app && <python> tools/video_to_pet_frames.py <视频> --name <动作名> --fps 24 --crop-bottom 40 --out-size 420 --scale 0.68
```
- `--name` **必须是 `ACTIONS` 里的名字**（idle/doze/sleepy/pickup/write/present；wake 不单独出素材）。
- ⚠️ **源片带水印必须 `--crop-bottom` 裁掉**（红线：实测原片水印在底部偏右，生成新片时平台自带水印也要去掉）。
- ⚠️ **转帧前先停守望 + 桌宠**（GDI+ 会锁住 PNG）；停桌宠务必**同时停守望**，否则它把桌宠拉回来。
- ⚠️ **删旧帧失败会静默中断转帧**（日志前面全正常，只有"✅ N 帧 → 目录"不出现）→ 转完**核对 meta 的 count/fps**。
- 内存：`_build_draw_cache` 建完预缩放缓存后**立刻释放原始位图**（不做 24fps 会顶到 500MB+）。
- 本机**没有 ffmpeg**：解码/切片段用托管 python 3.13.12 的 `imageio + imageio_ffmpeg + PIL + numpy`。
- 细节见 `docs/多动作状态机-2026-09-28.md`（含在 `bash` 之外的分段/边界重设流程）。

## 6. 音效

四段自带音轨（变困静音）、**峰值统一 60%**；`idle/sleepy/write` 循环播；右键「音效」是总开关；
winsound 单通道 → `_play()` 记 `_sfx_resume_at = now + 0.6` 自动接回。

## 6. 绘制路径的硬约束

- `_draw_pet()` 只有一条路径、**无回退分支**；调用处必须写
  `if self._anim_play_now() and self._draw_anim_frame(...)`（只写后半句会 `AttributeError`）。
- 🔴 **颜色一律 ARGB（8 位带 `0xFF`）**：`Surface.ellipse/poly/ctext/round_rect` 收 ARGB，
  写 6 位（如 `0x746556`）= **alpha=0 → 完全透明且不报错**。
- 帧缓存（预缩放）与 `_cache_sig()`：见 `docs/工程细节-性能-2026-09-30.md`（菜单卡顿那轮的产物）。
