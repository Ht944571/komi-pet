## 二、桌宠侧（`app/`）

### 1. 写字素材换代（另一个会话线，已生效）
- `assets/anim/write/` 换成 84 帧新素材；`_anim_meta.json` 带 `loop_start=33` + `split`（present 段起点）。
- ⚠️ 换素材后必查：`ANIM_MS` 必须与素材帧率同（现 **41ms/帧 ≈ 24.4fps**）；
  `SPLIT_RATIO`/`HEAD_SCALE` 按新素材实测重设。
- 用户还想**重做中间循环段的背景**（生成提示词已在 `写字动作-生成提示词.md`，含"B 段首尾帧必须一致"的循环要求）。

### 2. 菜单卡顿（本会话）—— 帧缓存三重旋钮
- **根因**：`_recreate_window()` 无条件重建帧缓存（解码 525 帧 + 逐帧 GDI+ 重采样 ≈ 3.2s），
  点「想法气泡」就冻 **3192ms**。拆解：Surface 0.04ms、clear 0.07ms，**全在 DrawImage 插值上（3.9ms/帧）**。
- **改法**：① `_cache_sig()` 签名（帧缓存只认显示尺寸）→ 气泡开关**不重建**（→3ms）；
  ② 真改尺寸走**后台线程建** + 用旧缓存**拉伸过渡**（UI 18.5ms 返回；那 16% 跳过规则要对
  `_cache_building` 放行，否则缩放跳档时她**整帧不画＝消失**）；③ 菜单条目构建的 DB 查询加 20s TTL；
  ④ 子菜单**停留 140ms 才展开**（原来鼠标扫过菜单会一路闪，每次 12ms）。
- 工具：`app/tools/_prof_menu.py`（菜单全链路画像）。细节：`docs/工程细节-性能-2026-09-30.md`。
- ⚠️ 别顺手降插值等级提速：Bilinear 比 HighQuality 快 2.3x，但实测**alpha 合成结果不同**（观感会变）。

### 3. 跟随切换卡顿（本会话）—— 直查视图 10.3 秒
- **根因**：跟随模式每次确认切换都同步调 `wb_follow.handoff_last_turn`，而它直查**视图** `v_turn_total`
  （多层 VIEW + 每行 `json_extract`）→ **单次 10304ms**，连切 5 次 = 46 秒冻结。
- **改法**：抽公共入口 `wb_hover_core.turn_src(conn, db_path)`（表在且非空用物化表 `dws_turn`，否则回退视图）
  + `_HANDOFF_CACHE` 5s TTL → **10304ms → 5.4ms**；同一处坑的 `_handoff_expand`（右键「生成接续摘要」）一并修。
- 🔴 **铁律**：任何"顺带查轮次"的地方都必须走 `turn_src()`（细节见 `docs/工程细节-性能-2026-09-30.md` §3）。
- 工具：`_prof_follow.py`（跟随逐段计时）、`_pet_fps.py`（像素哈希测"她还动吗"：24.4fps 正常，>1.5s 无变化=冻住）。

### 4. 联动关闭 / 守望（本会话）—— 桌宠无声消失的根修
- **现象**：桌宠一天无声消失 4 次（07:37 / 15:17 / 16:50 / 17:06），无 `linked_close`、无崩溃日志、守望也一起没。
- **根因链**：守望**单轮**判空就 `kill_whale()` × 探测会**瞬时闪空**
  （`CreateToolhelp32Snapshot` 失败被当成"没有进程"）→ 一次误判就强杀桌宠（强杀不留任何日志）。
- **改法**：
  - 桌宠侧宽限 **3s/2 次 → 30s/3 次**（`wb_motion.LINKED_CLOSE_GRACE_S` / `CONFIRM_CHECKS`）；
    并给三种关键动作**留痕**：`host_gone`（看不见宿主）/ `close_req`（收到关闭请求）/ `linked_close`（真退出，带判据）。
  - 守望侧：纯判定 `should_kill_on_session_end` 之外加 **`KillDebounce`**（连续 6 轮/25s 才灭杀）；
    **单实例互斥体** `KomiPetWhaleWatcher.SingleInstance`；全链路日志 `%TEMP%/komi-watcher.log`。
  - presence 侧：**三值语义**——快照失败返回 `None`（未知），`detect_detail` 跳过 L3、
    `detect_once` 返回 None（守望不判）、`PresenceDetector` 保留上一次集合（宿主判据不闪空）。
  - 看板 API 看门狗加**兜底拉守望**（桌宠+守望都没了 → 分离进程拉起守望，10 分钟冷却）。
- 🔴 **联动关闭的语义 = "任一已注册 agent"**（不是只跟 WorkBuddy）：关掉 WorkBuddy 但 opencode/zcode 还开着
  → 桌宠**不退出**（设计如此，别当 bug）。
- 细节：`docs/工程细节-守望与联动-2026-09-30.md`。
