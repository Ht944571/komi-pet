## 0. 先建立心智模型（3 个概念，读完再动手）

| 概念                      | 是什么                                       | 类比       |
| ----------------------- | ----------------------------------------- | -------- |
| **ArtMesh**             | 每个图层切成的**三角网格**                           | "可弯曲的布"  |
| **Deformer**            | **变形器**：把若干 ArtMesh 装进一个组，父级一动子级全跟着动      | "套娃的盒子"  |
| **Parameter + Keyform** | **参数与关键形**：参数=0 时物体在形态A，参数=1 时在形态B，中间自动插值 | "动画的关键帧" |

**绑骨 = 画网格 → 套层级 → 拖参数值摆形态。** 没有别的。

## 2. ⚠️ 最重要的一步：ArtMesh 分割（不做这步形变就是"整块平移"，很塑料）

选中一个 ArtMesh → 工具栏 **「自动分割」**（分割数/阈值）。参照表：

| 图层                                  | 建议网格                   | 原因            |
| ----------------------------------- | ---------------------- | ------------- |
| `eyes`、`highlight`、`eyelid_upper`   | **密**（阈值 1–2，分割数 8–12） | 眨眼要让它弯曲，密了才自然 |
| `head`、`hair_front`、`hair_side_l/r` | **中**（阈值 2–3）          | 转头时会拉伸        |
| `hair_back`、`body`、`arms`           | **中**                  | 呼吸摆动          |
| `skirt`                             | **中**（下半部密一点）          | 以后加物理摆动       |
| `legs`                              | **粗（2×2 就够）**          | 基本不动，省顶点      |

**每个 ArtMesh 都要勾掉「用矩形包围」**（如果有这个选项）——否则它只做整体位移。

## 3. 参数：**直接用 Cubism 自带的标准模板，别自己建**

> **2026-09-26 实测更新（看了你 Cubism 5.3 的界面）**：导入 PSD 后**参数面板已经自带**
> `角度X/Y/Z`、`左眼开闭`、`左眼微笑`、`右眼开闭`、`右眼微笑`… 一整套标准参数。
> **它们的底层 ID 正是运行时需要的 `ParamAngleX` / `ParamEyeLOpen` / `ParamEyeBallX` /
> `ParamMouthOpenY` / `ParamBreath`** —— 直接沿用即可。
> **不要自己新建参数**：手输名字才是拼写错误的唯一来源（名字错了运行时不会报错，只表现为"角色不动"，极难查）。

**必须确认这几个存在**（参数面板往下滚就有）：

| 显示名 | 底层 ID（运行时按它驱动） | 用途 |
|---|---|---|
| 角度X / Y / Z | `ParamAngleX` / `Y` / `Z` | 转头、点头、侧头 |
| 左眼开闭 / 右眼开闭 | `ParamEyeLOpen` / `ParamEyeROpen` | **眨眼（最小模型必需）** |
| 眼球X / Y | `ParamEyeBallX` / `Y` | 视线跟踪 |
| 呼吸 | `ParamBreath` | **呼吸（最小模型必需）** |
| 嘴开闭 | `ParamMouthOpenY` | 以后接说话 |
| 左眉上下 / 右眉上下 | `ParamBrowLY` / `ParamBrowRY` | 以后接表情 |

⚠️ **用哪几个参数，就一定要做对应的关键形**（§5/§6）。没做关键形的参数，运行时驱动了也没反应。

## 4. 变形器层级（照这个套娃结构建）

```
Root
├─ D_Body                     ← 躯干总控制
│   ├─ D_Skirt                （裙子）
│   ├─ D_Legs                 （腿）
│   └─ body / arms 的 ArtMesh
└─ D_Head                     ← 头部总控制
    ├─ hair_back / hair_side_l / hair_side_r / hair_front 的 ArtMesh
    ├─ D_Face                 ← 脸盘
    │   └─ head / blush / nose / mouth 的 ArtMesh
    └─ D_Eye_L / D_Eye_R      ← 左右眼各自一组
        ├─ eyes / highlight 的 ArtMesh
        └─ eyelid_upper 的 ArtMesh
```

做法：`变形器` 面板 → 新建（选「父级变形器」或「子级变形器」）→ 把对应 ArtMesh 拖进去。
**眼睛一定要分左右两组**，否则以后没法做单眼动作。

## 5. 关键形 A：呼吸（`ParamBreath`）

选中 `ParamBreath` → 值设为 `1` → 然后：

| 对象           | 操作   | 值（画布 942 高，按此比例）        |
| ------------ | ---- | ----------------------- |
| `D_Body`     | 整体上移 | **+3 px**               |
| `D_Head`     | 整体上移 | **+2 px**               |
| `hair_front` | 整体上移 | **+1 px**（头发滞后，有"活"的感觉） |

再把 `ParamBreath` 设回 `0` 确认回到原位。

> 原理：运行时我会让 `ParamBreath` 以 3 秒周期在 0↔1 之间正弦往复 → 角色就"呼吸"起来了。

---

## 6. 关键形 B：眨眼（`ParamEyeLOpen` / `ParamEyeROpen`）

**这是全篇最关键的一步。** 先估一下你图里眼睛的高度：`eyes` 层内容 y 约 408–517，
所以眼高 ≈ **109px**（在 942 高的画布上）。

对 **左眼**（`ParamEyeLOpen`）：

1. 参数值设 `1` → 全部原位（确认一下）
2. 参数值设 `0`：
   - 把 `D_Eye_L` 里的 **`eyelid_upper`** 整体**下移 ~110px**（盖住 `eyes` 和 `highlight`）
   - `head` 上移 **1px**（微点头，眨眼不孤立）
3. 回 `1` 检查：眼皮抬起，眼珠重现

对 **右眼**（`ParamEyeROpen`）：重复同样数值。

> 注意：`eyelid_upper` 是那两道粗睫毛线。让它"下来盖住眼睛"就是闭眼。
> 如果下移 110px 后还有缝，就再往下一点——**必须完全盖住 `eyes`**。
